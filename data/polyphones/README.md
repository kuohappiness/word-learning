# 多音字資料

App 在「輸入單一字」時要列出每個讀音和對應的常用詞（SPEC 2.2）。這裡整理的是常考的多音字，來源是一本多音字練習本的收字範圍，再全部對照教育部辭典。

## 檔案

| 檔案 | 誰寫 | 內容 |
|---|---|---|
| `units/NN.json` | 人＋AI 依照片整理 | 一個單元一個檔：收哪些字、書上的讀音分組、改寫後的白話義項、例詞、改寫後的練習題 |
| `../polyphones.json` | 程式產生 | App 讀的檔案：注音全部取自辭典，練習題附答案與選項 |
| `REVIEW.md` | 程式產生 | 給人逐字核對：書上讀音和辭典不一致、辭典查不到的地方列在最前面 |

產生：`python3 tools/build-polyphones.py <dict-revised.json>`（辭典檔取得方式見 `data/README.md`）。

## 規則

- **注音只取自辭典**。`book` 欄位是書上標的讀音，只用來比對，不會顯示。例詞的讀音先查辭典詞條，取出這個字所在位置的音；辭典沒有這個詞時，再看單字條目的釋義和例子有沒有寫到它。都沒有就不顯示注音。
- 書和辭典不一致時，一律以辭典為主，直接改：例詞移到辭典讀音那一組（沒有就新增一組），書上讀音辭典沒有的就不收；辭典沒收的例詞刪掉或換成辭典有的詞。每一處都記在 `skipped`，理由寫「以辭典為主」，`REVIEW.md` 會集中列在「已照辭典改正」。
- 不照抄原書：義項由 AI 依教育部釋義改寫成白話；例詞優先用辭典有收的詞；練習題的句子全部重寫。原書的題目與答案不放進 repo。
- 不適合兒少的義項或例詞放在 `skipped`，寫明原因。
- 改完單元檔後跑 `python3 tools/format-unit.py data/polyphones/units/*.json` 排成固定格式。
- 辭典用異體字收錄的詞（例如「祕魯」收在「秘魯」），在 `aliases` 註明要改查哪個寫法。

## 單元檔格式

```json
{
  "unit": 1,
  "page": 4,
  "aliases": { "祕魯": "秘魯" },
  "chars": {
    "便": [
      { "book": "ㄅㄧㄢˋ", "senses": [
        { "gloss": "做起來順手、不麻煩", "words": ["便利", "方便"] },
        { "gloss": "曬", "note": "同「曝」", "words": ["一暴十寒"] }
      ]}
    ]
  },
  "skipped": [ { "char": "扁", "book": "ㄅㄧㄢˇ", "what": "俗語「揍人」", "reason": "不適合兒少" } ],
  "practice": [
    { "type": "word", "char": "磅", "word": "英磅" },
    { "type": "sentence", "char": "便", "word": "便宜", "text": "這家文具店的筆又好寫又便宜。" },
    { "type": "pick", "char": "膀", "word": "膀胱", "text": "……膀胱……" },
    { "type": "odd", "char": "比", "words": ["比賽", "比肩", "比照", "比喻"] }
  ]
}
```

練習題四種：`word` 詞語填音、`sentence` 句子填音、`pick` 從幾個讀音選一個、`odd` 四個詞裡哪一個讀音不同。答案和選項不寫在單元檔，由程式從辭典推出；推不出來的題目不會進 App，並列在 `REVIEW.md`。

## 整理新一批照片的步驟

1. 照片轉正，每頁只取標題完整的那一個單元（邊緣露出的鄰頁不算），用單元編號去重。
2. 每個單元寫一個 `units/NN.json`：字依書上順序；讀音分組照書；義項用自己的話改寫，對照辭典釋義不偏離；例詞換成辭典有收的詞或自己寫的短語。
3. 依同樣比例自編練習題（約 4 題詞語、4 題句子、2 題選擇），句子正向、貼近 10–16 歲生活。
4. 跑 `tools/build-polyphones.py`，看 `REVIEW.md` 最前面的清單，修到只剩需要人決定的項目。
5. `node --test tests/*.test.mjs` 會再用 `data/revised/` 檢查一次注音與答案。
